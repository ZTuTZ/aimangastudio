# 导出 6GB 压力验收记录（2026-09-25）

本次在本地开发机运行了 V2 的按需压力测试，使用 Java 21 执行、按 Java 17 编译，测试 JVM 通过 Maven export-stress profile 限制为 -Xmx512m。这是**本地生产组包路径验收**，尚未替代宝塔预发布机上的磁盘、OSS 和并行负载演练。

执行命令（在 server/ 内）：

    JAVA_HOME=/Library/Java/JavaVirtualMachines/jdk-21.jdk/Contents/Home mvn -B -Pexport-stress -Dit.test=ExportResourceStressIT -Dexport.stress.entryBytes=300000000 verify

测试调用实际的 ExportTaskHandler.run、ExportTempFiles、检查点下载校验及外层 ZIP 发布组包路径。20 个作品的检查点由固定种子的伪随机流模拟，每个恰好 300,000,000 字节；未把 6GB 数据预先加载到内存。外部数据库、阶段执行和 OSS 由测试替身提供，因此本记录不声称完整线上链路已验证。
