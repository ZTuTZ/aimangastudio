# v2 需求与页面规格

> 定义角色、功能清单、页面信息架构与交互流程。前端与后端实现均以本文为准。

## 1. 角色

| 角色 | 代号 | 能力 |
|---|---|---|
| 系统管理员 | `ADMIN` | 全部功能：漫画生产（与 USER 相同）+ 账号管理（创建/停用/重置密码）+ 系统配置（AI 通道、OSS、提示词、并发参数）+ 风格预设管理 + 全局任务监控（所有用户） |
| 普通用户 | `USER` | 仅漫画生产：作品库、上传导入、两步生成、资产编辑、任务中心、个人改密。**不可见**系统配置（OSS/AI Key/提示词/并发） |

- 账号仅由 ADMIN 创建；无自助注册。
- 被停用账号登录被拒，其已有数据保留。

## 2. 功能清单

### 2.1 漫画生产（USER + ADMIN）

| 功能 | 说明 |
|---|---|
| 作品库 | **分页列表展示**（表格：作品名+简介、状态、画幅、色彩模式、话/页数、创建时间，行尾操作按钮：打开/删除）；**搜索条件：按名称、按状态**（服务端分页，SQL 走索引且不查询大字段）；支持删除（二次确认，级联删除话/页/资产） |
| 批量上传导入 | 一次选择多个 TXT/DOCX 文件（或逐个粘贴文本），每个文件/文本创建一部作品，**创建即自动入队第一步流水线**；导入时可设置：标题（默认文件名）、画幅（3:4 / 2:3 / 1:1 / 16:9，默认 3:4）、色彩模式（partial/monochrome/color，默认 partial）、风格预设（可选） |
| 第一步流水线（自动） | SPLIT 拆话 → 逐话 SCRIPT 六段式脚本 → ASSET 资产提取 →（可配置）SHEET 角色设定表；每一步产生任务记录，进度实时可见 |
| 话（章节）管理 | 话列表：序号、标题、状态（待处理/脚本生成中/脚本就绪/生成中/完成/部分失败）、页数；单话重新生成脚本；单话脚本编辑（原文 script_text 可改后重跑）；单话一键生成成品页 |
| 脚本编辑 | 页级脚本查看/编辑：旁白 narration、对白 dialogue（角色名+台词，逐行）、画面 visual；可手动新增/删除页 |
| 资产管理 | 四类资产（角色/场景/道具/服装）列表 + 编辑：名称、别名、描述、结构化字段（角色：年龄段/发型/配饰/上衣/下装/身份）；参考图上传（OSS）；单资产生成设定表（角色为六姿势图）；删除资产 |
| 一键生成成品页 | 范围=整部剧或某一话；色彩模式三选一；可选"跳过已生成页"；提交后生成任务实时进度 |
| 页画廊 | 缩略图网格（布局图/成品图切换），按话分组，状态角标（待生成/生成中/成功/失败+原因） |
| 页详情 | 大图查看；布局图 vs 成品图左右/滑动对比；脚本展示与编辑；操作：重生成布局图、重生成成品图、上色、清晰化、局部重绘（canvas 框选遮罩 + 提示词）、下载单页 |
| 任务中心 | 我的任务列表：类型、作品、状态、进度条、成功/失败计数、当前页、耗时、错误信息；操作：停止、重试（断点续跑）、删除；实时刷新（SSE，断线降级轮询） |
| 导出 | 按话/整部导出成品图 ZIP（打包命名：`作品名/第N话/第M页.png`）；单页直接下载 |
| 个人设置 | 修改自己的密码 |

### 2.2 管理后台（仅 ADMIN）

| 功能 | 说明 |
|---|---|
| 账号管理 | 用户列表（用户名/角色/状态/创建时间/作品数）；创建账号（用户名+初始密码+角色）；停用/启用；重置密码；删除（需二次确认，级联删除其作品？——默认不级联，仅停用，删除为高危操作需输入用户名确认） |
| 系统配置 | 分组表单：AI 文本通道（api_url/api_key/model/timeout/concurrency）、AI 生图通道、AI 编辑通道、生图并发与超时、任务并发（全局 worker 数、每用户并行任务数、单任务页级并发）、默认页数 storyboard_page_count、功能开关（自动拆话/自动角色图等）、OSS 配置（key/secret/bucket/region/endpoint/图片处理参数）；密钥保存后脱敏显示；"测试连通"按钮 |
| 提示词管理 | 各环节提示词模板（拆话/六段式脚本/布局/成图/上色/清晰化/局部重绘）在线编辑，含占位符说明与"恢复默认" |
| 风格预设 | 列表 + 新建/编辑/停用：名称、风格提示词、负面提示词、默认色彩模式、参考图（OSS）；USER 在创建作品/生成时选用 |
| 全局任务监控 | 所有用户的任务列表（可按用户/类型/状态筛选），可停止/重试；系统负载概览（运行中任务数、队列长度、AI 通道占用） |

## 3. 页面信息架构（前端路由）

```
/login                      登录页
/                           作品库（USER 与 ADMIN 的首页）
/projects/:id               作品详情（第一步工作区 + 第二步一键生成 + 页画廊，Tab 切换）
/projects/:id/pages/:pageId 页详情
/tasks                      任务中心（我的任务）
/settings                   个人设置（改密）
/admin/users                账号管理（ADMIN）
/admin/configs              系统配置（ADMIN，含提示词管理 Tab）
/admin/presets              风格预设（ADMIN）
/admin/tasks                全局任务监控（ADMIN）
```

- 路由守卫：未登录 → /login；USER 访问 /admin/* → 403 页。
- 全局布局：左侧导航（作品库/任务中心/个人设置 + ADMIN 分组）+ 顶部栏（当前用户、退出）。
- 全局任务状态入口：顶栏常驻"任务活动"指示器（运行中任务数角标，点击进入任务中心）。

## 4. 关键交互流程

### 4.1 批量上传（第一步启动）
1. 作品库点「上传故事」→ 弹窗：拖拽多文件（TXT/DOCX）或切换"粘贴文本"模式（可添加多条）。
2. 每条可改标题；统一设置画幅/色彩模式/风格预设。
3. 提交 → 后端为每条创建作品并各自入队 SPLIT 任务 → 前端跳回作品库，卡片显示"准备中"，可进任务中心看并行进度。

### 4.2 第一步完成后 → 编辑 → 第二步
1. 作品详情「剧本与资产」Tab：话列表（脚本就绪后可展开每页脚本编辑）、资产四类列表编辑。
2. 「生成成品」Tab：选范围（整部/某话）+ 色彩模式 + 跳过已生成 → 一键生成 → 生成任务进度实时显示（进度条 + 当前页）。
3. 完成后页画廊展示成品；失败页可单独重试。

### 4.3 页详情局部重绘
1. 成品图上进入"局部重绘" → canvas 覆盖层涂抹/框选遮罩区域 → 填写重绘提示词 → 提交 → 任务完成后新图替换（保留旧图到生成记录）。

## 5. 状态机（前端展示语义）

**作品**：0 准备中（流水线进行）→ 1 待出图（脚本就绪）→ 2 出图中 → 3 完成 → 4 部分失败
**话**：0 待处理 → 1 脚本生成中 → 2 脚本就绪 → 3 出图中 → 4 完成 → 5 部分失败
**页**：0 待生成 → 1 生成中 → 2 成功 → 3 失败（含 fail_reason）
**任务**：0 排队中 → 1 进行中 → 2 成功 → 3 失败 → 4 部分失败 → 5 已停止 → 6 停止中（CANCELING 过渡态）

## 6. 非功能需求

- 任务进度实时性：提交/进度变化 ≤ 2s 内推送到前端（SSE）。
- 并发能力基线：≥ 3 部作品同时 BATCH 生成互不阻塞；AI 生图通道并发默认 10（可配）。
- 故障恢复：服务重启后 1 分钟内自动恢复未完成任务执行；已完成页不重复生成。
- 安全：密码 BCrypt；JWT 有效期 + 刷新；所有接口鉴权；USER 无法通过任何 API 读取系统配置明文。
- 中文界面；组件空态/加载态/错误态统一。
